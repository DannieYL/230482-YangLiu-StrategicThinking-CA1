Labour is undoubtedly the largest controllable expense in the hospitality industry. However, when tourist numbers fluctuate from day to day, tourist attractions often struggle to get their staffing levels right. This usually results in either staff shortages that cause long waiting times and complaints, or overstaffing that wastes payroll budget. 
This project investigates labour optimization by developing a predictive staffing model for a real tourist attraction in Ireland. Using an anonymized dataset of daily operational records covering a 12-week period, the project will use Python to clean the data, find historical patterns, and build machine learning models to forecast future daily traffic. The final deliverables will include a clear visitor-to-staff ratio matrix and an interactive dashboard for stakeholders. 
Ultimately, this project aims to turn messy operational data into a practical business solution, helping management schedule the ideal number of staff needed to improve customer satisfaction and maintain profitability.
